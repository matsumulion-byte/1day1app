# 世界観光ガチャ

2026-09-27 / 世界観光の日。静的ファイルのみで動くThree.js製地球儀。60都市、連続重複なし。外部API・CDNへの実行時依存なし。Google Mapsリンクのみ外部サイト。

- 記念日出典: https://www.un.org/en/observances/tourism-day/background
- 地球テクスチャ: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg (Three.js examples)
- Three.js 0.169.0: MIT、vendor/THREE-LICENSE.txt
- 都市データは編集した旅行アイデア用の概算。距離は東京からの大圏距離。フライト時間には乗継の概算を含む。予算は1人・航空券込み3泊4日相当で、長距離都市の往復移動日数は別途必要。リアルタイム運航・価格・営業状況は参照しない。
- ドラッグ回転、ピンチ・ホイール拡縮に対応。動きを減らすOS設定では高速回転を省略。

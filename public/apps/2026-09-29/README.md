## 操作

画面左側の上げている前足を、押したまま下へ、上へ動かすと1回招く。十分に下げて離すと、自然に戻ったところで1回招く。小さなタップや操作キャンセルではカウントしない。キーボードはキャンバスにフォーカスして下矢印→上矢印。再読み込みで最初から。

## 実装

- 球・押し出した耳・チューブ状の絵付けによるオリジナル造形。外部モデルなし。
- 釉薬のクリアコート、微細なバンプ、スタジオ環境反射、スポットライトと影。小判の文字はCanvasTexture。
- Three.jsを同梱してCDNへの実行時依存を回避。ライセンスは `vendor/LICENSE-three.txt`。
- Pointer Events / pointer capture / 肩を軸にした減衰ばね。下げて上げる入力、または下げて離した後の復帰を1回としてカウント。キャンセル・二重カウントを防ぐ。
- 64候補。縁起物率は1〜5回98%、6〜15回58%、16回以降6%。
- 20回から約9秒以上、30回から約3.6秒以上の間隔で自動動作。51回から約0.4秒ごとに招く。
- DOM表示は最大4件。非表示タブでは進行停止。DPR上限2。共有ジオメトリ・マテリアル、固定の影解像度を使用。
- reduced-motionでは視差・身体と鈴の揺れ・テキストの移動を省略し、自動前足の振幅と頻度を抑える。20回以降は自動動作を休ませられる。

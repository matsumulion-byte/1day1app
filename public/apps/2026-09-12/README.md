# ドッキングしてください

`standalone.html` はCSSとJavaScriptを含む単一HTML版です。保存してブラウザで開けます。Three.jsをCDNから読み込むためネット接続が必要です。音声・画像アセットは使用しません。

公開用は `index.html` / `styles.css` / `script.js`。publicをルートとして `/apps/2026-09-12/` にアクセスしてください。

## 遊び方
- W / ↑：前進噴射。S / ↓：船の後方へ逆噴射。
- A D / ← →：左右回転。スマホは画面下のボタンを長押し。回転と噴射を同時操作できます。
- 噴射を離しても速度は維持されます。逆噴射は自動ブレーキではなく、現在の船の向きに対する逆方向の加速です。
- 緑のポートへ正面から、速度0.65 m/s以下・角度8°以内・中心ずれ0.65 m以内で接近すると成功。
- 高速接触・角度ずれ・ステーション本体との衝突・燃料切れ・運用エリア離脱は失敗。
- RまたはRETRYで最初から。最初のステージは中心に配置しており、短い前進噴射と慣性だけでも成功できます。

## 調整しやすいパラメータ
`script.js` 冒頭（単一HTML版ではscript内）の `CONFIG` を変更します。

| パラメータ | 初期値 | 内容 |
|---|---:|---|
| thrust | 1.05 | 前進加速度 |
| reverseThrust | 0.85 | 逆噴射加速度 |
| turnRate | 1.0 | 回転速度 rad/s |
| maxSpeed | 0.65 | 成功速度 m/s |
| maxAngle | 8 | 成功角度 ° |
| portHalfWidth | 0.65 | 許容中心ずれ m |
| fuelBurn | 2.8 | 噴射時の燃料消費 %/s |
| turnBurn | 0.35 | 回転時の燃料消費 %/s |
| startDistance | 19 | 初期位置 z |

判定の数値を変える場合は、HTMLの案内文と失敗メッセージの数値も合わせてください。単一HTML版と公開用分割版は同じ実装です。変更時は双方を更新してください。

# モザイク職人

軽量な5ステージのブラウザゲーム。外部通信・外部依存・音声なし。

`public` をドキュメントルートにして `/apps/2026-09-28/` を開く。

## 素材の差し替え

`stages.js` の `image`（公開ルートからの絶対URL）、`label`、`time`、`hint`、`targets` を編集。
各 target は `label`, `x`, `y`, `width`, `height`。座標は元画像に対する0〜1の相対値。
画像は5:6比率推奨。現在のSVGは架空の人物・架空の情報を使ったダミーイラスト。

## 採点

10×10ピクセルのモザイクセルを記録し、600×720の作業座標で正解矩形との交差面積を集計。
各ターゲット85%以上で保護成功。保護率85点、精度の基礎点10点、残り時間5点。
未保護ターゲット1つにつき20点減点。不要な塗り面積÷画像面積×140を減点（最大75点）。
0〜100に丸め、5ステージ平均を四捨五入して最終点数にする。全面塗りは最大25点。
ブラシは半径20/34/54、取り消しは直近30筆。画面を離れても時間は進む。

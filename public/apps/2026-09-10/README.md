# 松村ジャック

9月10日「屋外広告の日」のブラウザ3Dアプリ。
日付の出典：[日本屋外広告業団体連合会](https://nikkoren.or.jp/okugaikoukokunohi/about-okugaikoukokunohi.html)。

## 起動

リポジトリの `public` をHTTPのドキュメントルートにして `/apps/2026-09-10/` を開く。
Three.js 0.170.0を `vendor` に同梱。ランタイムの外部通信・APIキー・有料素材は不要。
写真はImageBitmapとCanvasで端末内処理。保存・送信は行わない。

## 実装

- 交差点、通り、路地、17棟の詳細建物と遠景、69面の広告。
- 顔の全面LED、横長、縦組み、反復ポスター、流れる文字、発光屋上サイン。
- 24秒の連鎖切り替え、夕方から夜への移行、上昇カメラ、スキップ。
- 自動遊覧／自由散策、WASD・矢印キー、ドラッグ、仮想スティック。
- 建物のAABB衝突と街の境界。カメラルートは道路内。
- インスタンシング、端末別の解像度・画角。光のにじみと路面反射は軽量な疑似表現。
- 再生成前に古い広告テクスチャをdispose。画像変更時にImageBitmapをclose。
- WebGL初期化失敗・コンテキスト喪失・画像読み込み失敗時の案内。

## 検証記録

Codex内ブラウザで実際に実行。1280×720、390×844、320×568で確認。

- 写真なしで開始し、24秒後に全69面が切り替わって夜間の自動遊覧へ到達。
- テスト用の縦長顔画像を選択し、ドラッグ・拡大率変更、写真削除を確認。
- 日本語40文字を入力し、写真との合成、看板の折り返し・縮小を確認。
- スキップ、もう一度、広告変更、自由散策と遊覧の切り替えを確認。
- PCキー入力で座標が変化。ドラッグで視点が変化。
- モバイルサイズで仮想スティック移動、右ドラッグ、ダブルタップを確認。scrollY=0、visualViewport.scale=1。
- 実際の経路を1,001点サンプリングし、建物・境界への侵入なし。全建物の中心と街の外側が進入不可であることを検証。
- 再実行後のGPUテクスチャ数が増え続けないことを確認（PCの確認経路では100枚で安定）。
- アプリのコンソールにエラー・警告なし。
- HTML、CSS、JS、同梱Three.jsのHTTP 200を確認。
- `npm run check:app -- 2026-09-10`、`npm run build`を実行。

実機のiPhone／Androidでの性能、OSの写真選択画面・ソフトキーボード、WebGL非対応端末そのものは未検証。

# MONORAIL 917

2026-09-17 / Three.jsで構築した、昭和未来都市を走るモノレール運転ゲーム。

`public` をドキュメントルートにして `/apps/2026-09-17/` を開く。ビルド不要。Three.js 0.160.1 は `vendor/` に同梱（MIT、ライセンス同梱）。外部通信・画像アセット不要。

- ↑ / W: 押している間加速、離すと惰行
- ↓ / S: 通常ブレーキ。最高速度80km/hで停止距離は約173m
- Space: 非常ブレーキ
- 小画面には同じ機能のタッチボタンを表示
- フォーカスを失うと一時停止・入力解除

中央未来 (400m) → ニュータウン北 (890m) → 第七码頭 (1420m)。目標の65m手前から18m先までが停車受付範囲。速度0.08m/s未満を0.7秒保つと採点。18mを超える通過はOVERRUN（0点）。目標から遠い場所で停止しても再加速可能。停車後4秒で自動出発。

誤差±0.5m以内 PERFECT（1000点）、±2m以内 GOOD、±5m以内 OK、それ以上 OVER。マイナスは手前、プラスは行き過ぎ。3駅合計3000点満点。

物理・採点検証: `node --test public/apps/2026-09-17/engine.test.mjs`

ブラウザ統合検証: `/apps/2026-09-17/verify.html` の `RUN DRIVE TEST` で入力イベントによる約2分の通し運転、非常停止、早期停止、3駅採点、自動出発、リトライを確認できる。`RUN TOUCH TEST` はブラウザ幅700px以下で実行する（タッチは合成イベント。実機のOSジェスチャー検証を代替しない）。

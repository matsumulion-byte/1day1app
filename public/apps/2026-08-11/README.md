# 馬鹿判定機

質問に回答するのではなく、6つの意味不明な実技試験に取り組む行動そのものから「馬鹿度」を測定する、スマホファーストの1ページ診断アプリです。

## 起動方法

リポジトリのルートで次を実行します。

```sh
npm install
npm run dev
```

ブラウザで `http://localhost:3000/apps/2026-08-11/` を開きます。

## 使用技術

- HTML / CSS / Vanilla JavaScript
- Pointer Events（マウス・タッチの共通入力）
- DeviceMotion API（対応端末での振動検知）
- Web Audio API（操作音）
- Web Share API / X Intent URL（結果共有）

外部ライブラリ、データベース、永続ストレージは使用しません。再読み込みすると測定は最初から始まります。

## 診断ロジックの概要

各ステージで取得した回数、所要時間、入力、衝動的な操作などを6指標（指示を疑わない度、無駄な努力、好奇心、連打性、諦めの悪さ、ノリの良さ）へ重み付けします。6指標の平均を基礎に下駄を加え、実際の行動差を残しながら、多くの結果が60〜95%付近になるよう調整しています。完全な乱数は使いません。

## 各ステージの採点方法

1. **逃げる赤ボタン**: 赤ボタンを追いかけた回数を、無駄な努力と諦めの悪さへ加点します。
2. **無意味な円周運動**: 完遂した周回数と所要時間を記録し、指示を疑わない度、無駄な努力、ノリの良さへ反映します。
3. **絶対に押すなボタン**: 押したか、残り何秒で押したかを記録し、好奇心と衝動傾向へ反映します。押さない選択も判定可能です。
4. **スマホを振れ**: 振動回数と加速度、100%以降の超過努力を記録します。DeviceMotionが使えない環境では連打ボタンが同じ役割を担います。
5. **「馬鹿」と入力**: 指定文字列を正しく自己入力した事実を、指示追従性とノリの良さへ加点します。
6. **結果を見るまでが長い**: 確認ボタンを最後まで押した回数を、好奇心、連打性、諦めの悪さへ反映します。
